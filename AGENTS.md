# Repository Instructions

DOCxWIRE converts `.docx` articles to clean HTML and publishes them to Joomla 5.

## Rules

- Commits, pushes, and PRs are user-initiated only.

## Spec-driven workflow (OpenSpec)

Features are specified before they are built. Every change moves through explore → propose → review → apply → archive.

- Artifacts live in `openspec/`: `specs/` is the source of truth, `changes/` holds in-motion changes, `changes/archive/` the completed ones.
- A change folder is committed together with the code it describes; archiving (move to `changes/archive/` + spec sync) is its own commit.
- Workflow skills ship in `.agents/skills/openspec-*/`; they are generated by the OpenSpec CLI (`openspec init` / `openspec update`), so a fresh checkout is usable without it. Do not edit them by hand.

## Definition of done

- `make ci` is green (lint, type check, tests at 100% coverage).

## CodeGraph

- If a `.codegraph/` index exists, prefer `codegraph_explore` (MCP) or `codegraph explore` (shell) over grep/read for locating and understanding code. Without an index, skip CodeGraph entirely — indexing is the user's decision.
